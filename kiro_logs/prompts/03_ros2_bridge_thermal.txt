1. sim/ros_pub.py: class RosPub(node_name="inspection_drone"). rclpy.init() if not already initialised. Methods:
   - pose(pos, quat_xyzw, vel=None): pos/vel are length-3 world-frame numpy arrays. Publishes TF odom->base_link,
     nav_msgs/Odometry on /odom (frame odom, child base_link), and appends to nav_msgs/Path /path (frame map) whenever
     the drone moved >= 0.15 m since the last appended pose (publish /path at most 5 Hz). A static TF map->odom
     (identity) is published once at construction via tf2_ros.StaticTransformBroadcaster-equivalent (/tf_static,
     TRANSIENT_LOCAL QoS). Use tf2_msgs/TFMessage publishers directly (no tf2_ros dependency needed if simpler).
   - sensor_tf(child, pos, quat_xyzw, parent="base_link"): dynamic TF for a sensor relative to base_link (the gimbal moves).
   - cloud(P, frame="os0_lidar", topic="/lidar/points"): P is an (N,3) float32 array in the sensor frame. PointCloud2
     with x,y,z float32 fields, built from the numpy buffer directly (fast, no per-point Python loops).
   - map(Pw): (N,3) world-frame points, accumulated by the caller. Voxel-downsample to 0.10 m (numpy unique on integer
     voxel keys), keep at most 400k points, publish PointCloud2 on /map in frame map with fields x,y,z,intensity where
     intensity = z (so RViz can colour by height). Rate-limit internally to 1 Hz.
   - image(topic, img, frame, encoding="rgb8"): sensor_msgs/Image from an HxWx3 uint8 array; also accept HxW float32
     with encoding "32FC1". Rate-limit per topic to 10 Hz.
   - mission(waypoints): list of (pos(3), target(3), element_name_str). Publishes /mission (nav_msgs/Path, frame map) and
     /mission/markers (MarkerArray: small spheres at each waypoint, a LINE_STRIP through them, TEXT labels at the

     data/defects_gt.json for the real format and adapt. Publishes /defects (MarkerArray, frame map, TRANSIENT_LOCAL):

   synth(labels, id2class, depth, t, ambient_c=12.0, rng=None) -> (temp_c float32 HxW, ironbow uint8 HxWx3 RGB)
   - labels: HxW integer semantic id image; id2class: dict id->class name string. Unknown/unlabelled ids = "sky".
   - Per-class base temperatures relative to ambient, e.g. sky -25, water -3, granite 0, granite_wet -2.5,
     concrete +1, asphalt +6, steel +2, steel_rust +2.5, brick +1.5, vegetation -1, vehicle +15, boat +3,
     drone +8, defect_moisture -4, defect_delamination +3.5, defect_crack -1.5, default 0.
   - Add a smooth low-frequency spatial variation (+-0.6 C, e.g. upsampled random noise seeded per class so it is
     stable over time), atmospheric attenuation toward ambient with depth (tau ~ exp(-depth/400)), a Gaussian optical
     blur (sigma ~1 px), and temporal NETD noise (~0.05 C, from rng).
   - Ironbow colour map (black-blue-purple-red-orange-yellow-white), auto-ranged per frame with 2nd/98th percentile and

   - Output resized to 640x512 with INTER_NEAREST for labels (do the resize before colouring).
