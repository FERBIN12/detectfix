Detector accuracy vs. ground truth

From eval_bag.py: each ground-truth defect is matched to at most one detection (closest first, within the match radius, same element). Precision = share of detections that are real; recall = share of real defects found.

Hardware health monitoring simulated telemetry

Battery, motors/thrusters, thermals, data links and leak sensors for each vehicle. The recorded bags contain no hardware telemetry, so these values are a deterministic mock (same mission, same values). Each status (OK / WARN / FAULT) is set by fixed thresholds in pipeline/hardware.py. Mission and sensor data quality below it is real.

ROV

The ROV has no GPS underwater; it navigates on a DVL (Doppler velocity log). Drift is the gap between where it believed it was and the simulator's true position, which bounds how accurately underwater defects are placed. A sonar hit counts as camera-confirmed only if a co-located camera frame is clear enough (RMS contrast ≥ 0.03). On a drone-only mission this panel shows labelled filler, never invented values.
